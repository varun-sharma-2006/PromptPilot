# KarmaQuiz (Team PromptPilot)

A prompt-engineered workflow that generates, quality-checks and competency-tags multiple-choice
questions from government training material, and summarises a learner's competency gaps.
Problem statement: SIH26101 (iGOT Karmayogi), from the course Problem Bank.
